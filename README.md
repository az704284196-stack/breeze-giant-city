# 布瑞泽 · 巨兽之城

> 一头从设定图里直接走出来的巨兽，落进一座有三百多栋楼、六百多人的城市。
> 在这里 **体型** 是唯一的货币：踩碎、吞下、抢走 —— 你碰过的一切都会变成你的身高。

单文件 Canvas 游戏，**不需要安装任何东西**：直接用浏览器打开 `index.html` 就能玩，离线可用。

## 在线玩

- GitHub Pages：`https://<你的用户名>.github.io/breeze-giant-city/`
- 或者下载 `布瑞泽-巨兽之城-分享版.html`（单文件，素材已内嵌）双击即可，手机也能玩（自动出现虚拟摇杆与按键）

## 玩法

| 操作 | 说明 |
|---|---|
| `WASD` / 方向键 / 手机摇杆 | 移动 |
| `空格` / 鼠标左键 / 踩踏键 | 踩踏：压扁人群、砸塌楼房与山体、踩碎星球 |
| `E`（可长按）/ 吞食键 | 吞食：吃人、吃食物、吃车辆、吞小行星 |
| `Q`（按住）/ 抢夺键 | 抢夺体型：同时吸走射程内所有竞争者的体型 |
| `F` / 牵引键 | 牵引（**吸收之旅专属**）：把地图上所有竞争者拉到身前并眩晕 3 秒 |
| `Shift` / 冲刺键 | 冲刺 |
| `P` / `M` | 暂停 / 静音 |

- **剧情模式**：吸收三头竞争者即通关。
- **吸收之旅（无尽）**：体型无上限。到 **山脉级** 会切换到群山与巨型设施的地图（机场 / 体育场 / 光伏阵列 / 巨塔 / 微缩城市 / 河流），到 **恒星级** 切换到宇宙地图（踩星球与星系），到 **宇宙级** 触发终章。

## 机制

- **踩踏别人变大**：落地冲击波把整条街的人压扁，地面留下深棕色坑洞
- **踩踏建筑变大**：站在楼下砸下去，高楼塌成碎片与尘云；比自己高的山体推得动但推不塌（只有身高达到它的 72% 才啃得动）
- **吃人变大**：按 E 张口吞下，比踩踏更补
- **吃东西变大**：街边烤肉、汉堡、蛋糕、汽水 —— 最快的成长捷径
- **抢夺他人体型**：按住 Q 同时吸走多个竞争者的体型，吸到对手峰值的 5% 即整个吸收

## 素材与构建

游戏内的角色贴图**直接取自创作者设定图**（自动抠底），造型未作改动：

- `assets/breeze-{front,side,back}.png`：站立三视图
- `assets/walk-{front,side,back}-{0..7}.png`：走路循环 24 帧（含抬脚露出的青蓝肉垫）
- `assets/ending.png`：终章立绘

`tools/` 下的脚本用于从原始设定图重新生成贴图（需要 Python + Pillow + numpy）：

```
python tools/make-walk.py        # 从走上循环图抠出 24 帧
python tools/make-sprites.py     # 从三视图设定图抠出站立贴图
node tools/make-share.js         # 生成内嵌素材的单文件分享版
node tools/deploy-github.js <TOKEN>   # 通过 GitHub API 一键建仓并上传
```
