把音效文件放进这个文件夹，游戏会自动改用它们（找不到就用内置合成音）。

需要的文件名（mp3 / wav / ogg 都可以，改后缀时同步改 breeze-giant-city.html 里的 SAMPLES）：

  step.mp3       踩踏脚步（哥斯拉式的沉重落地声）—— 空格/左键踩踏时播放
  collapse.mp3   建筑崩塌碎裂声 —— 楼房被砸塌时播放
  eat.mp3        吞食声 —— 预留给吞食（目前用合成音）
  steal.mp3      抢夺体型声 —— 预留给抢夺（目前用合成音）

说明：
- 没有文件时不会报错，游戏使用内置的 WebAudio 合成音（低频下潜 + 轰鸣 + 碎屑）。
- 每个音效播放时会做 ±5% 的随机变调，避免连续踩踏听起来重复。
- 建议时长：step 0.6~1.5 秒，collapse 1.5~3 秒，避免叠加时糊掉。
- 文件不要太大（<300KB 为宜），否则首次进游戏会有一点点加载延迟。
